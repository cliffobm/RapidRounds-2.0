# Historical integration candidates

These `.template` files preserve the first integration drafts created while package downloads were blocked. The current implementations are now in `lib/auth*.ts`, `components/AuthScreen.tsx`, `lib/profilePhoto.ts`, `components/ProfileScreen.tsx`, and `lib/speech*.ts` / `components/ReadAloud.tsx`.

Do not copy these templates over the active source. The active versions add reviewed cancellation, persistence, callback, accessibility, and error-handling changes that the templates do not contain. Follow `../AUTH_SETUP.md` to configure the installed integrations.
